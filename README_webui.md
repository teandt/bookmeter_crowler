# Bookmeter Crawler Web UI マニュアル

`cr_bookmeter/bookmeter_web.py` は、`bookmeter_crawl.py` の主要な CLI オプション相当の処理をブラウザから実行するための Web UI です。

積読本・読んだ本・書籍詳細の取得、DB確認、タイトル検索、不要な書籍詳細データ削除、ブクログ形式CSV出力を画面から操作できます。

## 前提

- Python の仮想環境を作成し、`requirements` の依存パッケージをインストールしておきます。
- 読書メーターのユーザーIDを `cr_bookmeter/env/.env` に設定しておきます。

依存パッケージの準備例:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements
```

設定ファイルは `cr_bookmeter/env/.env.example` を参考にして、`cr_bookmeter/env/.env` を作成してください。

## 起動方法

リポジトリ直下で仮想環境を有効化してから起動します。

```bash
source venv/bin/activate
python3 cr_bookmeter/bookmeter_web.py
```

デフォルトでは `127.0.0.1:8000` で起動します。ブラウザで次の URL を開きます。

```text
http://127.0.0.1:8000/
```

ホストやポートを変更する場合:

```bash
python3 cr_bookmeter/bookmeter_web.py --host 127.0.0.1 --port 8080
```

停止するときは、起動したターミナルで `Ctrl+C` を押します。

## 画面構成

Web UI のトップ画面には次の操作領域があります。

- 実行
- 状態とログ
- CSV出力
- 不要詳細データ削除
- 検索
- DB確認

処理中のジョブがある場合、DB更新やクロール処理の競合を避けるため、他のボタン操作は無効化されます。

## 実行

「実行」では、取得したい対象をチェックしてクロールを開始します。

| 画面操作 | 対応する CLI オプション | 内容 |
| --- | --- | --- |
| 積読本 | `-st`, `--stacked` | 積読本リストを取得します。 |
| 読んだ本 | `-rd`, `--read` | 読んだ本リストを取得します。 |
| 書籍詳細 | `-dt`, `--detail` | 詳細未取得の書籍詳細を取得します。 |
| すべて取得 | `-all`, `--all` | 積読本、読んだ本、書籍詳細をまとめて取得します。 |

「選択して実行」を押すと、チェックした対象だけを実行します。何も選択していない場合はエラーになります。

「すべて取得」を押すと、CLI の `--all` と同じ扱いで次の順に実行します。

1. 積読本リスト取得
2. 読んだ本リスト取得
3. 書籍詳細取得

書籍詳細のみを実行した場合は、詳細未取得の URL があるときだけクロールします。すべて取得済みの場合は、クロールせずログにその旨を表示します。

内部的には、Web UI から `bookmeter_crawl.py` をサブプロセスとして起動します。CLI のログは Web UI のジョブログに集約されます。

## 状態とログ

「状態とログ」では、現在または直近のジョブ状態を確認できます。

表示される主な状態:

- `queued`: 実行待ち
- `running`: 実行中
- `succeeded`: 成功
- `failed`: 失敗

ログ欄には、処理開始、CLI 起動コマンド、クロールログ、CSV出力ログ、削除ログ、例外発生時の traceback などが表示されます。

画面は約2秒ごとに `/api/status` を確認し、状態とログを更新します。

## DB確認

「DB確認」では、SQLite に保存済みのデータをテーブル形式で確認できます。

| タブ | 対応する CLI オプション | 表示内容 |
| --- | --- | --- |
| 読んだ本 | `-ckrd`, `--checkread` 相当 | 読んだ本リストと紐づく書籍詳細 |
| 積読本 | `-ckst`, `--checkstacked` 相当 | 積読本リストと紐づく書籍詳細 |
| 書籍詳細 | `-ckd`, `--checkdetail` 相当 | 書籍詳細データ |

読んだ本・積読本の一覧では、リスト側のタイトル、著者、日付、URL に加えて、詳細データ側のタイトルや ASIN も確認できます。詳細が未取得の場合、詳細タイトルや ASIN は空欄になります。

## 検索

「検索」では、DB に登録された書籍をタイトルで部分一致検索できます。

キーワードはスペース区切りで複数指定できます。複数キーワードを入力した場合は AND 条件で検索します。

検索対象:

| 画面の選択肢 | API 値 | 内容 |
| --- | --- | --- |
| 読んだ本と積読本 | `all` | 読んだ本と積読本の両方を検索します。 |
| 読んだ本 | `read` | 読んだ本だけを検索します。 |
| 積読本 | `stacked` | 積読本だけを検索します。 |

検索結果には次の項目が表示されます。

- 区分
- タイトル
- 著者
- 日付
- 読書メーターの書籍URL

並び順は CLI の `--search` と同じ自然順ソートを使い、タイトルの降順で表示します。数字や一部のローマ数字を巻数として扱うため、シリーズものの確認に使いやすい順序になります。

## CSV出力

「CSV出力」では、ブクログ形式の CSV を作成してダウンロードできます。

### 前提条件を確認

「前提条件を確認」を押すと、CSV 出力に必要なデータが揃っているか確認します。

確認項目:

- 読んだ本リストに詳細未取得の本がないこと
- 積読本リストに詳細未取得の本がないこと
- 読んだ本リストに ASIN 未取得の本がないこと
- 積読本リストに ASIN 未取得の本がないこと

不足がある場合は、件数が画面に表示されます。詳細データ不足がある場合は、先に「書籍詳細」取得を実行してください。

### CSV出力

「CSV出力」を押すと、CLI の `-csv`, `--csv` 相当の処理を実行します。

出力先:

```text
cr_bookmeter/csv/booklog.csv
```

文字コード:

```text
sjis
```

CSV 出力に必要なデータが不足している場合、CSV は作成されず、ログに不足内容が表示されます。

### CSV取得

「CSV取得」を押すと、作成済みの `booklog.csv` をダウンロードします。

CSV ファイルがまだ存在しない場合は、先に CSV 出力を実行するようエラーが返ります。

## 不要詳細データ削除

「不要詳細データ削除」では、リスト側に存在しない古い書籍詳細データを削除できます。

削除対象は次の条件に一致する `BookDetail` です。

- `BookDetail` に存在する
- `ReadBooks` には存在しない
- `StackedBooks` にも存在しない

「削除対象を確認」を押すと、削除候補の件数とタイトルを確認できます。

「確認して削除」を押すと、削除対象を再取得したうえで確認ダイアログを表示します。承認すると CLI の `-deldt`, `--deletedetail` 相当の削除処理をジョブとして実行します。

削除結果は「状態とログ」に表示されます。

## 排他制御

Web UI は同時に1つのジョブだけを実行します。

実行中扱いになる状態:

- `queued`
- `running`

実行中のジョブがある場合、次の操作は開始できません。

- クロール
- CSV出力
- CSV前提条件確認
- DB確認
- 検索
- 削除対象確認
- 不要詳細データ削除

これは Scrapy/Twisted の reactor と SQLite 更新の競合を避けるためです。

## API

画面は次の API を使用します。通常はブラウザ画面から操作すれば十分です。

| メソッド | パス | 内容 |
| --- | --- | --- |
| `GET` | `/` | Web UI の HTML を表示します。 |
| `GET` | `/api/status` | 現在または直近のジョブ状態とログを返します。 |
| `POST` | `/api/run` | クロールジョブを開始します。 |
| `POST` | `/api/csv` | CSV出力ジョブを開始します。 |
| `GET` | `/api/csv/status` | CSV出力の前提条件を確認します。 |
| `GET` | `/api/download/csv` | 作成済み CSV をダウンロードします。 |
| `GET` | `/api/books?kind=read` | 読んだ本リストを返します。 |
| `GET` | `/api/books?kind=stacked` | 積読本リストを返します。 |
| `GET` | `/api/books?kind=detail` | 書籍詳細リストを返します。 |
| `GET` | `/api/search?q=...&target=all` | タイトル検索を実行します。 |
| `GET` | `/api/delete-details/preview` | 不要詳細データの削除候補を返します。 |
| `POST` | `/api/delete-details` | 不要詳細データ削除ジョブを開始します。 |

### `/api/run` のリクエスト例

積読本と読んだ本を取得する例:

```json
{
  "stacked": true,
  "read": true,
  "detail": false
}
```

すべて取得する例:

```json
{
  "all": true
}
```

### `/api/status` のレスポンス例

```json
{
  "running": true,
  "job": {
    "name": "クロール",
    "status": "running",
    "started_at": "2026-07-08T10:00:00",
    "finished_at": null,
    "error": null,
    "result": null,
    "logs": []
  }
}
```

## エラー時の見方

エラーは画面上のメッセージ、または「状態とログ」に表示されます。

よくある原因:

- 取得対象を選ばずに「選択して実行」を押した
- 別の処理が実行中に操作した
- CSV 出力に必要な詳細データまたは ASIN が不足している
- `cr_bookmeter/csv/booklog.csv` が存在しない状態で CSV 取得を押した
- 読書メーター側の一時的なアクセス制限や 503 エラーが発生した

読書メーター側の一時的なエラーはクロールログに表示されます。詳細未取得のデータは次回の書籍詳細取得で再取得対象になります。

## CLI との対応

Web UI は次の CLI 機能に対応しています。

| CLI オプション | Web UI |
| --- | --- |
| `-st`, `--stacked` | 実行 > 積読本 |
| `-rd`, `--read` | 実行 > 読んだ本 |
| `-dt`, `--detail` | 実行 > 書籍詳細 |
| `-all`, `--all` | 実行 > すべて取得 |
| `-ckst`, `--checkstacked` | DB確認 > 積読本 |
| `-ckrd`, `--checkread` | DB確認 > 読んだ本 |
| `-ckd`, `--checkdetail` | DB確認 > 書籍詳細 |
| `-deldt`, `--deletedetail` | 不要詳細データ削除 |
| `-csv`, `--csv` | CSV出力 |
| `-s`, `--search` | 検索 |
| `-t`, `--target` | 検索対象 |

CLI の詳細は次のコマンドでも確認できます。

```bash
cd cr_bookmeter
python3 bookmeter_crawl.py --help
```
